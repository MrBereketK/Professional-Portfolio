# Bereket Kiros Portfolio

![ts](https://badgen.net/badge/Built%20With/TypeScript/blue)

My personal portfolio website, built with Next.js and TypeScript. Tailwind CSS and GSAP are used for styling and animations, with light & dark themes (dark by default).

## Features

- Responsive Design
- Light & Dark themes
- Fully Accessible
- SEO Friendly

## Tech Stack

**Frontend** - [NextJS](https://nextjs.org/), [React](https://reactjs.org/), [TypeScript](https://www.typescriptlang.org/)
**Styling** - [Tailwind CSS](https://tailwindcss.com/)
**Animations** - [GSAP](https://greenstock.com/)
**State Management** - [Zustand](https://zustand-demo.pmnd.rs/)
**Deployment** - [Vercel](https://vercel.com/)

## Running Locally

Clone the project and go to the project directory.

```bash
cd portifolio
```

Install dependencies

```bash
npm install
```

Set your contact email in `.env`

```bash
NEXT_PUBLIC_EMAIL = "you@example.com"
```

Start the server

```bash
npm run dev
```
